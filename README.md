# SkullFlame — сайт онлайн-школы видеомонтажа

Концепт лендинга и личного кабинета школы монтажа. Проект для портфолио: оплата, заявки и данные в кабинете — демонстрационные.

## Что внутри

- **Хромовый стиль с цветом тарифов.** Акцент сайта — хром; когда открыт блок тарифов, весь хром (логотип, кнопки, заголовки, свечение) окрашивается в цвет выбранного тарифа: PRO — фиолетовый, MAX — бирюзово-синий, ULTRA — оранжевый.
- **3D-знак в hero** на three.js: матовая звезда внутри кольца, реагирует на курсор.
- **Интерактивный таймлайн**: плейхед ходит за мышью, клипы слева от него светятся неоном.
- **Ниши монтажа**: карточки с 3D-наклоном и анимированными иллюстрациями, по клику — окно с описанием ниши и примерным заработком.
- **«Как проходит обучение»** проигрывается прокруткой, как таймлайн.
- **Тарифы** с подсветкой рамки у курсора и формой записи.
- **Орбитальное меню** за кнопкой с домиком: раскрывается кругом из кнопки, выбранный пункт втягивается в сферу.
- **Демо-кабинет**: «Мои курсы», «Профиль», «Поддержка».
- Плавные переходы между блоками при прокрутке, своя страница 404, адаптив под телефон, учёт настройки «уменьшить движение».

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, three.js, Framer Motion, lucide-react.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Структура

- `app/` — страницы: главная, `/courses`, `/profile`, `/support`, 404; глобальные стили и анимации в `app/globals.css`
- `components/` — блоки сайта (Hero, Program, How, Pricing, Works, Header и др.)
- `components/ui/` — переиспользуемые компоненты: подсветка рамки `spotlight-card`, орбитальное меню `radial-orbital-timeline`
